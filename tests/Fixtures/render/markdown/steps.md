Follow these steps to add a user.

:::steps
1. Open the users page

   ![Users page](/storage/codex/users.png "The users list")

2. Click **Add** and fill in the form

   > [!TIP]
   > Use the company e-mail address.

3. Save the user

   ```bash
   php artisan codex:scan
   ```
:::

The new user can sign in right away.
